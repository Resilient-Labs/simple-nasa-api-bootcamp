# 🚀 Project: Simple NASA API

### Goal: Enable your user to enter a date and return the picture/video of the day from NASA's API
The application uses NASA’s API to retrieve and display the image or video, title, date, and explanation associated with the selected day.

## How It Works
- User selects a date
- The app adds the selected date to the NASA APOD API request
- NASA returns the Astronomy Picture of the Day data
- The app displays the title, image or video, date, and explanation

## Features
- Select a date to view NASA’s Astronomy Picture of the Day.
- Display the image or video returned by the API.

## API Used
- NASA Astronomy Picture of the Day API
[https://api.nasa.gov/planetary/apod]

## Technologies Used
- HTML
- CSS
- JavaScript
- NASA API
