# 🚀 Project: Simple NASA API

### Goal: Enable your user to enter a date and return the picture/video of the day from NASA's API

To use this app, please clone this repo and then run the project. Open the index.html in your browser. Once you have opened the index.html in your browser, you can choose the date and then click the button. 

NASA's API will provide an answer -- as long as you have an active internet connection and the world is not ending. 

Enjoy!
