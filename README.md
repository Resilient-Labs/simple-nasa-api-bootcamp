# 🚀 NASA Picture of the Day

### JavaScript API Bootcamp Assignment

## About the Project

This assignment focuses on building a simple application that lets users explore NASA's Astronomy Picture of the Day.

The idea is to let someone choose a date and see the picture or video NASA featured that day.

The goal is to practice working with APIs, retrieving information, and displaying that information on a webpage using JavaScript.

## Project Goals

- Let users select a date.
- Request information from NASA's Astronomy Picture of the Day API.
- Display the image or video associated with that date.
- Practice working with JSON data.
- Use JavaScript to update the webpage with the API response.

## Planned Tech Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- NASA Astronomy Picture of the Day API

## How It Would Work

1. The user selects a date.
2. JavaScript sends a request to NASA's API.
3. The API returns information about the selected day's picture or video.
4. JavaScript reads the response and displays the media on the page.

## Concepts to Practice

- Making API requests using `fetch()`.
- Working with asynchronous JavaScript.
- Understanding JSON responses.
- Using DOM manipulation to update HTML elements.
- Handling different types of API responses.
- Working with user input.
