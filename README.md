## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/NASA-Photo-Generator.git
````

2. Navigate to the project directory:

```bash
cd NASA-Photo-Generator
```

3. Open Project File

4. Use in browser
   
## Usage

1. Use calendar to enter date of your choosing.
2. Use submit button to see the photo of the day from that date.
