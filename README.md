## NASA Stargazers 
A web application that lets users pick a date to view NASA's Astronomy Picture of the Day (APOD). It displays the image or video, title, and explanation for the chosen date.

## Features
Date Picker: Select any date to retrieve media directly from NASA's official archive.

Image & Video Support: Automatically detects whether the media is an image or a video and dynamically updates the layout.

Detailed Descriptions: Displays the official NASA title and comprehensive explanation for each daily entry.

## API Used
NASA APOD API: [https://api.nasa.gov/planetary/apod](https://api.nasa.gov/planetary/apod)

## How It Works
The user inputs a date and clicks the search button.

The app fetches data from the APOD API using the selected date.

If the media type is an image, it renders an image element; if it is a video, it renders an iframe or video container.

The title, explanation, and media source update on the page dynamically.
