# 🚀 Simple NASA API
Enable your user to enter a date and return the picture/video of the day from NASA's API

https://github.com/user-attachments/assets/60d5f9af-9c39-4ec4-928d-39acde474e5a

## How It's Made:
Nasa  APoD App is built using the following technologies:

- **JavaScript (JS)**: Employed for client-side functionality.
- **NASA Astronomy Photo of the Day API**: Fetched and populated data based on the user inputted date

## What I Learned
- How to use an async/await to have a brief loading text
- Use conditionals based on the data type to present an image or an iframe
- **Code Organization** to clearly route client and server side data

**If you would like to download and try out my code**
Go to NASA APoD and get an API key : https://api.nasa.gov/
- Add a key.js file to the js folder
